# Native full-stack validation

Validated locally on 2026-10-03 using fictional documents and generated media.

**28/28 integration checks passed**, plus **13/13 pinned-image policy regressions** without network or provider credentials. Image, audio and video input probes passed through LiteLLM to OpenRouter. These are observed control/capability checks, not a production quality or jailbreak-resistance benchmark.

## Configuration

- Google SSO at OAuth2 Proxy; two real accounts in separate Chrome profiles, both normal Open WebUI users.
- Open WebUI v0.11.4-slim, digest pinned; native Knowledge/groups and pgvector 0.8.6 on PostgreSQL 17.
- One pinned LiteLLM gateway for chat, vision/multimodal input, embeddings and reranking.
- Gemini 2.5 Flash, GPT-4.1 mini, Gemini 3 Flash Preview, text-embedding-3-small, Voyage rerank-3-lite; see the [route table](openwebui.md#model-routes).
- Shared live Presidio for text, mandatory input/context/output controls, buffered answers, separate metadata-only event volumes.
- Provider key has a $5 total cap; no recurring reset. Its expiry is unset by operator choice. The measured key usage at this checkpoint was $0.003387 (under the authorized $0.50 test budget). No credits were purchased.

## Reproduce

Follow [setup and walkthrough](openwebui.md#reproduce-the-evidence). Offline regressions cover missing/cross-user signed identity/context, streaming bypass, output exfiltration/PII/prompt echo, PII outage, sanitized errors, removal of the old poisoned prompt, reranker failure and concurrent user binding. CI runs these suites in digest-pinned images with `--network none`. Hosted model calls are opt-in via `--live`; normal CI uses no OpenRouter key.

The host offline suite passed 80 discovered tests: 65 executed, 2 live Presidio cases skipped, and 13 native-image cases skipped there and executed separately in their pinned images. Site validation passed 39 tests, TypeScript checking and a Vite production build.
